Home Assistant for Microsoft 365 Copilot

Configure the plugin and download it, ready to upload to Copilot Cowork.

1Webhook URL

The remote webhook URL of your ha-mcp server. In the HA Custom Component, open Configure and copy the webhook URL for remote clients.

The URL is the only credential for your Home Assistant. It stays in this browser and is only sent to your own server, when you load its tool list.

2Version

Raise it on every upload, or Microsoft 365 won't pick up the change.

3Copilot Chat tools

Cowork discovers all tools live from your server. The Copilot Chat agent only gets the tools you pick here. Keep it to about 10 so it chooses the right tool reliably.

Loading tool list…

    4Download and install

    1. In Copilot Cowork, go to Customize → Plugins → Upload plugin and choose ha-mcp-plugin.zip.
    2. Share it with Only you, and select Apply.
    3. After a few minutes, the Home Assistant agent also shows up in the Copilot Chat agents pane.
    4. To change a setting later, come back here, change it, raise the version and upload the new zip.
